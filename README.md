# 🖥️ tp-nsi2026

> **Proposition de Correction des sujets de TP de l'épreuve du Baccalauréat de NSI 2026**

---

## 📚 À propos

Ce dépôt regroupe des **propositions de correction** pour les sujets de TP (Travaux Pratiques) de l'épreuve pratique du **Baccalauréat de Numérique et Sciences Informatiques (NSI) — session 2026**.

Les corrections sont proposées à titre indicatif et pédagogique. Il peut exister plusieurs approches valides pour chaque exercice.

---

## 🗂️ Structure du dépôt

| Dossier / Fichier | Description |
|---|---|
| *(à venir)* | Les sujets seront classés par numéro |

---

## 🚀 Comment utiliser ce dépôt

1. **Parcourir** les dossiers pour trouver le sujet qui vous intéresse.
2. **Lire** l'énoncé du sujet officiel (disponible sur le site de l'Éducation Nationale).
3. **Comparer** votre solution avec la proposition de correction.
4. **Comprendre** les différences et améliorations possibles.

---

## 🐍 Langage utilisé

Les corrections sont rédigées en **Python**, conformément aux attendus de l'épreuve NSI.

---

## ⚠️ Avertissement

Ces corrections sont des **propositions** et non des corrections officielles. Elles peuvent contenir des erreurs ou des approches différentes de celles attendues par les correcteurs.

---

## 🤝 Contribuer

Les contributions sont les bienvenues ! Si vous repérez une erreur ou souhaitez proposer une alternative :
